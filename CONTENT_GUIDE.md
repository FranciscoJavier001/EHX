# Content guide

- Register a new organization or operator in `catalog.ts`. Devices and transmissions derive their origin from the catalog and use stable fictional IDs.
- Add an event type and channel language in the catalog. Update the engine's severity and consequence rules when the event changes device state. Link reports and SIGINT records through the event suffix.
- Add a document to the catalog and define access rules in `visibleDocument`. Retain its identifier, source organization, date and cross-references.
- Create a story with a named relay, public dispatch, synthetic cipher, gated ledger and a link to another story. Update the discovery conditions and add a test that traverses the new path.
- Add assignments with stable IDs and discovery objectives. Include the new ID in the catalog used by save validation.
- Add a specific OMEGA intent before broad terms in `omega.ts`. Derive answers from records or authored lore and cover precedence in tests.

All entities, transmissions, evidence and destinations belong to the fictional universe.
